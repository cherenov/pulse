# PULSE

**Personal Unit for Health and Life Evaluation**

PULSE is an offline-first Flutter app for monitoring health biomarkers and telemetry. It is designed for crews operating without a reliable network: log measurements, review status by category, and get timely alerts when values leave a safe range.

## Goals

- Track blood, urine, non-invasive, and eye-health indicators in one place
- Detect physiological anomalies from recent telemetry
- Work fully on-device, including voice feedback for critical events
